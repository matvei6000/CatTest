# CatTest
Привет, это тестовая версия кликера, для прокачки нюха и копания 

Инструкция:
1. Скачайте кликер для вашей версии браузера.
2. В папке cattast найдите и запустите cattast.exe.
3. После запуска вы увидите:
   
   <img width="1918" height="984" alt="Снимок экрана 2026-09-09 201436" src="https://github.com/user-attachments/assets/509d53ee-122a-4ac0-8acf-f25db618dcfe" />
   в строку Email введите почту на которую регистрировали аккаунт.
   После этого вы увидите:

   
   <img width="498" height="87" alt="Снимок экрана 2026-09-09 201533" src="https://github.com/user-attachments/assets/5d9e544b-d048-413d-ba07-4d8755e4a846" />
   
   в поле "Пароль" введите пароль от аккаунта.


   <img width="304" height="68" alt="Снимок экрана 2026-09-09 201708" src="https://github.com/user-attachments/assets/8182df07-1ab5-41af-946e-bd6ced26f29a" />

   теперь вы можете вводить команды.

Гайд по командам:
1. копать
2. нюхать

Рядом с командой можно указать число.
Пример: копать 10

Команда будет выполнена 10 раз.
